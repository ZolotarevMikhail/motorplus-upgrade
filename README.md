# АВТОСЕРВИС «МОТОР+» — демо «апгрейд до/после»

Демонстрация услуги «апгрейд сайта»: один и тот же вымышленный автосервис,
**до** (типовой сайт 2010-х, каких много — собран намеренно с ошибками) и
**после** (то, что делаю под заказ). Компании не существует, это портфолио-демо.

## Смотреть

1. `do/index.html` — версия «до» (аутентичная windows-1251)
2. `posle/index.html` — версия «после»
3. `АУДИТ.md` — таблица «проблема → чем мешает → что сделано» + баллы

## Что демонстрирует апгрейд

- **Оффер вместо «лидеров рынка»**: конкретные цены строкой, «смету диктую после осмотра и до начала работ».
- **Один CTA** «Записаться на завтра» ×2 и минимальная форма (2 поля) вместо ссылок «в пустоту».
- **Адаптив**: телефон (390px) и компьютер, без горизонтального скролла (версия «до» — фиксированная таблица 980px, это часть «до»).
- **SEO**: UTF-8, уникальные title/description, один H1, alt у картинки, OG + Twitter Card + canonical, схема AutoRepair, robots.txt и sitemap.xml.
- **Устойчивость**: контент виден без JavaScript (появление блоков прячет и проявляет сам скрипт), анимации только через transform/opacity.
- **Юр-минимум**: согласие на обработку данных под формой, дисклеймер в футере.
